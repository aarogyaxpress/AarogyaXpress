# Deployment configuration

Before deploying, configure the browser-safe Supabase URL and publishable/anon key plus server-only Supabase service key and AI provider keys in Vercel. Apply the profile setup migration in `supabase/migrations/20261008_profile_setup.sql` through the Supabase SQL Editor. See [deployment setup](docs/deployment-setup.md) for the full variable list and instructions.
